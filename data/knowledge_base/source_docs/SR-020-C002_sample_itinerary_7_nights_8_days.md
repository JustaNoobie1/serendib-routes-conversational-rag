# Sample Itinerary - 7 Nights / 8 Days

**Chunk ID:** SR-020-C002

This is a 7-NIGHT / 8-DAY itinerary. Do not label it as a 7-day trip.

Classic first journey:
Day 1: Airport -> Sigiriya/Dambulla.
Day 2: Sigiriya and Cultural Triangle.
Day 3: Dambulla -> Kandy.
Day 4: Kandy -> hill country; scenic rail may be considered only if schedule and seats are confirmed.
Day 5: Ella / hill-country exploration.
Day 6: Ella -> south coast or Galle.
Day 7: Galle + beach / relaxed final day.
Day 8: Airport.

Slow premium / couples structure:
2 nights Cultural Triangle + 2 nights Kandy/hills + 3 nights south coast. This structure prioritizes fewer hotel changes and a calmer pace.
